# VC 플랫폼 (Value Chain Platform) — 건강기능식품 B2B OEM/ODM 매칭 MVP

> VC = **Value Chain**. 화면 어디에도 브이씨바이오·VCBio 표기를 쓰지 않는다(대표 지시 2026-09-20).

영업력이 부족한 중소 제조 공장과 유통사를 연결하는 매칭 플랫폼의 MVP 저장소입니다.

## 스택

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Supabase** (DB·인증, 예정)
- **Vercel** (배포, 예정)

## 실행법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.
